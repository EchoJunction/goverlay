These account-free synthetic fixtures were written and read by Qt 6.12.0
`QSettings::IniFormat`, with fallbacks disabled for reading. They contain no
Prism installation data. Tests decode only the isolated `Env=` scalar; they do
not parse or interpret its JSON.

`scalar-quoted.ini` was generated by the research `qsettings-fixture.cpp` in the
separate integration documentation repository. Its compact JSON has two entries,
Unicode, punctuation, quotes, backslashes and JSON newline/tab escapes. Qt emits
outer quotes because the string contains commas. QSettings reading returns:

```json
{"KEEP":"quote\" slash\\ newline\n tab\t","MANGOHUD_CONFIGFILE":"/tmp/Prism test/日本語,=#;\\path/overlay.conf"}
```

`scalar-unquoted.ini` was generated by this equivalent standalone Qt program:

```cpp
#include <QCoreApplication>
#include <QSettings>
#include <QJsonDocument>
#include <QJsonObject>
int main(int argc, char **argv) {
    QCoreApplication app(argc, argv);
    QSettings s(argv[1], QSettings::IniFormat);
    s.setValue("Env", QString::fromUtf8(QJsonDocument(QJsonObject{
        {"MANGOHUD_CONFIGFILE", QString::fromUtf8("/tmp/Synthetic 日本語/overlay.conf")}
    }).toJson(QJsonDocument::Compact)));
    s.sync();
    return s.status();
}
```

Compile with `g++ -fPIC scalar.cpp -o scalar $(pkg-config --cflags --libs Qt6Core)`
and run with a new temporary INI path. Qt itself emits the unquoted escaped
form; no quotes were manually stripped. QSettings reading returns:

```json
{"MANGOHUD_CONFIGFILE":"/tmp/Synthetic 日本語/overlay.conf"}
```

This mirrors the scalar form observed after Prism normalizes a single-entry
Env. It does not establish application launch or binding behavior. Commas
outside INI quotes are Qt list syntax and the decoder refuses them. The decoder
also conservatively refuses comments, raw controls, quote fragments, outer
whitespace, typed QVariant payloads and unsupported escape forms rather than
attempting a complete Qt INI parser.
